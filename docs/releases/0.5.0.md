Sub Tracker is now **Notch Sub**: AI subscription usage at the Mac notch or in the menu bar.

- Coming from Sub Tracker? Quit it, install Notch Sub, then delete `Sub Tracker.app`. Saved accounts, Keychain items, and settings move over on first launch. macOS may ask once to let Notch Sub read the old Keychain items.
- Notch Sub opens at login by default when run from Applications. Turn it off in Settings.
- New bundle identifier `com.sagar.notchsub` and repository [Sagar-CK/notch-sub](https://github.com/Sagar-CK/notch-sub). Old links redirect.

Requires macOS 14+. The universal DMG and ZIP support Apple Silicon and Intel. Downloads are ad-hoc signed, not Apple-notarized. Check `SHA256SUMS.txt` to verify downloads.
