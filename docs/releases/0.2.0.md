## Changes

- Gemini Code Assist model quotas from local Gemini CLI sign-ins.
- Antigravity model-group allowances and reset times through `agy` 1.1.11 or later.
- Google provider icons and CLI controls.
- A notch overflow count for additional active providers.

Google's individual AI Pro and Ultra coding access moved to [Antigravity](https://developers.google.com/gemini-code-assist/docs/deprecations/code-assist-individuals). Gemini support applies to eligible Code Assist accounts. Google sign-ins and switching remain managed by their own CLIs.

## Install

Download **Sub-Tracker-0.2.0-macOS-universal.dmg**, open it, and drag **Sub Tracker** into **Applications**. The ZIP contains the same app. Requires macOS 14 or later on Apple Silicon or Intel.

Quit the previous version before replacing it. Local account data stays in place. No credentials or personal configuration are included in the downloads.

This preview is **ad-hoc signed, not Apple-notarized**. SHA-256 checksums are included. If macOS blocks it, build from source or follow [Apple's guidance](https://support.apple.com/en-us/102445) for apps you trust.

## Validation

24 checks cover quota parsing, local account handling, safe switching, CLI execution bounds, and process cleanup. Codex and Claude have been verified with live accounts. Z.ai, Gemini, and Antigravity still need live-account validation. Provider endpoints can change.
