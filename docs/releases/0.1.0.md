## Install

Download **Sub-Tracker-0.1.0-macOS-universal.dmg**, open it, and drag **Sub Tracker** into **Applications**. Open the app from Applications. The same download supports Apple Silicon and Intel Macs running macOS 14 or later.

The ZIP contains the same app if you prefer that format. `SHA256SUMS.txt` contains checksums for both files.

This preview is **ad-hoc signed, not Apple-notarized**. macOS may block the first launch. You can build from source instead, or consult [Apple's instructions for opening downloaded apps](https://support.apple.com/en-us/102445) after checking that you trust the download. No Gatekeeper-disabling commands are needed.

## Build it yourself

Requires a Swift 6 toolchain:

```sh
git clone https://github.com/Sagar-CK/sub-tracker.git
cd sub-tracker
./scripts/install.sh
```

The app uses each person's own local sign-ins. No accounts, tokens, usage history, or personal configuration are bundled.

## Known limits

Codex and Claude usage have been verified with live accounts. Z.ai has parser checks but still needs a live Coding Plan key validation. Claude Desktop and ZCode keep separate sign-ins, keychain-only Codex credentials are not supported, and running clients must restart after an account switch. Monthly bills and estimated dollar usage are not displayed.
