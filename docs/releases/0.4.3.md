Sub Tracker shows AI subscription usage at the Mac notch or in the menu bar.

- Detect verified local accounts and show remaining allowances, resets, and credits.
- Cycle compact readings or pin a provider in Settings.
- Switch supported local Codex, Claude Code, and Z.ai accounts.
- Choose Notch, Menu bar, or Both. Macs without a notch use the menu bar.

Requires macOS 14+. The universal DMG and ZIP support Apple Silicon and Intel. Downloads are ad-hoc signed, not Apple-notarized. Check `SHA256SUMS.txt` to verify downloads.

Codex, Claude, and Cursor have live-account validation. Other integrations need further live testing. Devin/Windsurf cache-only accounts remain hidden. See the README and provider setup documentation for limitations.
